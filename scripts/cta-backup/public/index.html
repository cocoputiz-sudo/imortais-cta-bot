IMORTAIS Backups

Aplicativo pessoal de Igor Perini para guardar cópias do banco de dados do bot de CTAs da guilda IMORTAIS em sua própria conta do Google Drive.

Como funciona

Uma rotina no servidor Debian identifica o encerramento de CTAs, gera uma cópia consistente do PostgreSQL, criptografa o arquivo e o envia à pasta privada IMORTAIS-CTA-BOT-BACKUPS. Cada cópia acompanha um manifesto para conferir sua integridade.

A integração usa rclone e um cliente OAuth próprio. O titular da conta autoriza o Google Drive no navegador. Estas páginas são informativas e não solicitam login, senhas ou arquivos.

Uso atual

A rotina está configurada para o ambiente de homologação do Debian. A proteção do banco de produção exige uma configuração específica. O aplicativo não é disponibilizado como serviço de backup para terceiros.
